# IRTAKI — Documentation du projet

## 1. Présentation

IRTAKI est le projet logiciel développé dans ce dépôt.

Ce dossier contient la documentation technique et le suivi du projet.

## 2. Organisation de la documentation

- `architecture/` — Architecture générale du projet, composants, flux et choix techniques structurants.
- `checkpoints/` — Historique des checkpoints importants du projet.
- `decisions/` — Décisions techniques et fonctionnelles importantes, avec leur contexte et leur justification.
- `development/` — Documentation de l'environnement de développement, des procédures et des conventions.

## 3. Environnement technique actuel

- Next.js 16.3.5
- React 19.2.8
- TypeScript 5.9.3
- Tailwind CSS 4.3.3
- ESLint 9.39.5
- Prettier 3.9.6
- Vitest 5.0.0
- React Testing Library 16.3.3
- Node.js 24.21.0
- pnpm 10.33.0

## 4. Gestion du projet

Le projet utilise Git pour le suivi des modifications et GitHub pour la sauvegarde distante.

Les modifications importantes doivent être enregistrées par des commits Git identifiables.

Les étapes majeures du projet doivent également être protégées par des checkpoints.

## 5. État actuel

Le projet se trouve actuellement dans :

**CHAT 01 — Étape 01 : Initialisation du projet**

La préparation de l'environnement de test avec Vitest et React Testing Library est terminée.

## 6. Principe de travail

Le développement d'IRTAKI est réalisé progressivement, par étapes validées.

Avant de passer à une étape suivante :

1. vérifier le résultat ;
2. exécuter les validations nécessaires ;
3. enregistrer les modifications dans Git ;
4. effectuer une sauvegarde distante lorsque le checkpoint est validé.
