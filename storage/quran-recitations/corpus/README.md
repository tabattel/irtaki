# Corpus des récitations admissibles

Ce répertoire est réservé aux fichiers audio dont le WER final est
exactement égal à 0 %, après normalisation versionnée.

Les enregistrements ayant un WER supérieur à zéro ne doivent pas
être conservés ici.

Les métadonnées de chaque récitation devront notamment identifier :
- l'utilisateur principal ;
- le Learner ;
- la riwaya ;
- l'identifiant de l'ayah ;
- l'identifiant unique de la récitation ;
- le modèle et sa version ;
- la version de normalisation ;
- le WER final ;
- le format, la durée et les caractéristiques audio.

La persistance et les règles d'accès seront définies dans le service
et la base de données. Ce répertoire ne doit pas être versionné.
